# My First Project with ReactJS and Tailwind CSS

A clean React starter built with Vite and Tailwind CSS.

## Getting started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates the production build in `dist`.
- `npm run lint` checks the source files.
- `npm run preview` previews the production build locally.

## Files for GitHub

Commit the app source, public assets, project configuration, lockfile, and this README. Do not commit `node_modules`, generated `dist` output, local environment files, or logs. `.gitignore` excludes these local/generated files; `.env.example` is allowed for documenting required environment variable names without secret values.
